# 사내 보안 프로그램 제작 프로젝트

내부에서 사용할 보안 프로그램 개발을 위한 정보 조사, 기술 데이터 수집, 학습 프로젝트.

## 참여 인원
2명

## 폴더 구성
- `docs/` — 프로젝트 문서 (마크다운)
  - `project-overview.md` — 프로젝트 배경, 목표, 제약, 전체 흐름 요약
  - `study-roadmap.md` — 지식 습득부터 개발까지 전체 로드맵
  - `curriculum.md` — 지식 습득 단계 상세 커리큘럼
  - `study-notes.md` — 일자별 학습 기록
  - `case-studies.md` — 보안 사례 수집·정리 (계속 추가되는 문서)
  - `versioning-policy.md` — 문서 버전 관리 기준 (필독)

이 저장소는 마크다운 문서만 관리합니다. 워드 종합 보고서는 필요할 때 별도로 생성하며 저장소에는 올리지 않습니다.

## 시작하기 전에
`docs/versioning-policy.md`를 먼저 읽어주세요. 모든 문서는 메이저.마이너(`v1.1` 형식) 버전을 상단에 표기하고, 문서 하단 "버전 이력" 표에 변경 위치와 내용을 기록합니다. 모든 문서는 v1.1을 공식 시작점으로 삼습니다.

## 커밋 규칙
커밋 메시지에 어떤 문서가 어떤 버전으로 바뀌었는지 명시합니다.

```
docs(case-studies): v1.1 -> v1.2, 사례 4 추가
docs(study-notes): v1.2 -> v1.3, 08-22 학습 기록 추가
```
