# 지식 습득 단계 — 상세 커리큘럼

전체 로드맵은 `study-roadmap.md`, 프로젝트 배경은 `project-overview.md` 참고. 이 문서는 현재 진행 중인 "필요 지식 습득" 단계만 상세히 다룬다. 추천 총 기간은 4~4.5개월(2~4인 기준).

## 트랙 A — OS/네트워크 기초 (1~4주차, 이후 macOS는 5~8주차)

이 트랙이 없으면 이후 보안 개념이 암기 위주가 되므로 가장 먼저 다진다.

**주제**
- TCP/IP, 포트, 라우팅, DNS, ARP, VLAN 개념
- Windows 내부구조: 프로세스/스레드, 레지스트리, 서비스, 이벤트 로그
- macOS 내부구조: launchd, 프로세스 모델, 코드사이닝/공증(notarization)

**추천 자료 (무료)**
- 널널한 개발자 TV (YouTube) — 네트워크 기초 강의
- 혼자 공부하는 네트워크 재생목록 (YouTube)
- Microsoft Learn 한국어 문서 — Process Explorer, Process Monitor 공식 문서
- Sysinternals 도구 직접 실습: Process Explorer, Process Monitor, Autoruns (이론보다 실제로 설치해서 눌러보는 게 습득이 빠름)
- Apple 공식 Endpoint Security 문서 (이 단계에서는 개념 이해 목적으로만, 엔타이틀먼트 신청은 이후 단계)

**체크포인트**: 자신의 PC에서 Process Monitor로 특정 프로그램 실행 시 어떤 레지스트리/파일 접근이 일어나는지 직접 추적해볼 수 있으면 통과.

## 트랙 B — 보안 개념 및 공격 기법 (5~14주차)

**기초 개념 (5~8주차)**
- CIA 트라이어드(기밀성/무결성/가용성)
- 인증(authentication) vs 인가(authorization)
- 암호화 기초: 대칭키/비대칭키, 해시 함수
- 악성코드 분류: 바이러스/웜/트로이목마/랜섬웨어/스파이웨어 차이
- 탐지 방식: 시그니처 기반 탐지 vs 행위 기반(heuristic/behavioral) 탐지

**공격 기법 심화 (9~14주차)**
- MITRE ATT&CK 프레임워크 전체 구조 학습: 초기 침투 → 실행 → 지속성 → 권한상승 → 방어회피 → 자격증명 탈취 → 탐색 → **횡적 이동(Lateral Movement)** → 수집 → 유출 → 영향
- 이 중 횡적 이동 단계를 우선순위로 둔다 — "감염 확산 차단"이라는 프로젝트 목표와 직결되기 때문
- 사례별 학습: 랜섬웨어(예: WannaCry의 SMB 취약점을 통한 확산 방식), DDoS, CSRF 등을 각각 감염경로, 공격방법, 피해규모, 알려진 사례, 방어/예방/치료 방법으로 나눠 정리
- 각 사례를 ATT&CK 기법 번호와 매핑하며 학습하면 이후 탐지 로직 설계 시 그대로 재사용 가능

**추천 자료**
- MITRE ATT&CK 공식 사이트 (프레임워크 원본)
- TryHackMe 무료 "Cyber Defense" 계열 트랙 (개념+실습 병행)

**체크포인트**: 랜섬웨어 사례 하나를 골라 ATT&CK 단계별로 어떤 기법이 쓰였는지 스스로 표로 정리할 수 있으면 통과.

## 트랙 C — 기존 보안 기술 조사 (9주차~18주차, 트랙 B와 일부 병행)

실제 개발과 가장 직결되는 트랙.

**Windows 화이트리스트 (9~12주차)**
- AppLocker 공식 문서
- WDAC(Windows Defender Application Control) 공식 문서
- 자체 구현 전에 OS 내장 기능만으로 목표(오탐 예외처리)가 어디까지 커버되는지 먼저 확인

**오픈소스 EDR (13~16주차)**
- Wazuh 문서 정독 (최우선 레퍼런스): 에이전트-서버 구조, 인증 방식, 탐지 룰(디코더/룰 체계)이 이미 100~1000대 규모를 전제로 문서화되어 있어 참고 가치가 높음
- osquery 문서: 단말 상태를 SQL 질의로 조회하는 접근 방식, 화이트리스트/이상탐지 양쪽에 응용 가능
- Velociraptor (여력이 되면 추가로)

**네트워크 격리 기술 (17~18주차)**
- NAC(802.1X) 개념
- VLAN 동적 격리
- 방화벽/스위치 API를 이용한 특정 단말 자동 격리 방식

**추천 실습**: 개인 테스트 환경(가상머신)에 Wazuh를 직접 설치하여 에이전트 1~2대를 연결해보고, 구조를 몸으로 익히는 것을 18주차 목표로 삼는다.

**체크포인트**: Wazuh를 로컬 환경에 설치하고 테스트 에이전트에서 발생한 이벤트가 중앙 서버 대시보드에 표시되는 것까지 확인할 수 있으면 이 단계 통과.
