# 사내 보안 프로그램 제작 — 전체 로드맵

프로젝트 배경과 목표는 `project-overview.md` 참고. 이 문서는 지식 습득부터 개발까지 전체 단계를 다룬다. 지식 습득 단계의 상세 커리큘럼은 `curriculum.md`, 사례 수집은 `case-studies.md`에 별도로 정리했다.

## 0단계 — 아키텍처 밑그림
에이전트(각 단말)-중앙서버 구조, 단말 고유 ID 체계, 에이전트-서버 통신 방식(예: HTTPS 폴링, mTLS)을 결정한다. 100~1000대 규모를 소수 인원이 관리하려면 이 구조 설계가 선행되어야 한다.

## 1단계 — 지식 습득 + 사례 수집 (현재 단계, 병행 진행)
네트워크/OS 기초, 보안 개념 및 공격 기법, 기존 보안 제품 기술을 3개 트랙으로 나눠 학습하며, 동시에 실제 공격 사례를 수집·정리한다.

- **트랙 A (OS/네트워크 기초)**: TCP/IP, Windows/macOS 내부구조
- **트랙 B (보안 개념/공격 기법)**: CIA 트라이어드, MITRE ATT&CK 기반 랜섬웨어·DDoS·CSRF 등 사례 학습
- **트랙 C (기존 보안 기술)**: AppLocker/WDAC, Wazuh/osquery 등 오픈소스 EDR, NAC/네트워크 격리 기술
- **사례 수집 (병행)**: 트랙 B 학습과 함께 실제 사고 사례를 `case-studies.md`에 계속 추가. 감염경로/공격방법/피해규모/방어·예방·치료 방법을 정리하고 ATT&CK 단계와 매핑

추천 기간은 약 4~4.5개월(2~4인 기준)이며, 상세 주차별 계획과 추천 자료는 `curriculum.md`, 수집된 사례는 `case-studies.md`를 참고한다.

## 2단계 — 서버 인프라 하드닝
중앙 서버가 뚫리면 연결된 전체 단말이 위험해지므로, 엔드포인트 기능 개발보다 먼저 진행한다. mTLS 상호인증, 최소권한 계정 설정, 로그/감사 체계를 갖춘다.

## 3단계 — Windows 우선 프로토타입
테스트 PC 2~3대에 에이전트를 설치하고 개별 ID로 서버에 등록, 화이트리스트 적용, 이상행위 탐지 시 자동 격리까지 이어지는 흐름을 검증한다. Windows가 대다수이므로 먼저 진행한다.

## 4단계 — macOS 확장 검토
Windows 프로토타입이 안정화된 후, Apple Endpoint Security Framework 엔타이틀먼트 신청 여부와 Mac 지원 범위를 결정한다.

## 5단계 — 검증 및 단계적 확대
소수 PC에서 성공하면 부서 단위로 점진 확대한다(예: 10 → 50 → 200대). 100~1000대를 한 번에 확대하지 않는다.
