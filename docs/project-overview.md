# 사내 보안 프로그램 제작 — 프로젝트 개요

## 배경
사내 중앙 관리 서버를 구축하던 중, 서버 자체를 보호할 보안 체계의 필요성을 느끼면서 자체 보안 프로그램 제작으로 프로젝트가 확장되었다. 담당자가 별도로 없고, 보안 관련 지식이 전무한 상태에서 시작하여 지식 습득부터 단계적으로 진행 중이다.

## 궁극적 목표
현재 시중 보안 프로그램들은 엑셀/PPT 등 오피스 프로그램의 크랙 버전을 실행하면 이를 위협으로 간주해 함께 차단하는 경우가 있다. 이 프로젝트는 다음 두 가지를 자체 구현하는 것을 목표로 한다.

1. **화이트리스트(예외처리) 기능**: 시그니처 오탐이 예상되거나 실제 오탐이 발생하는 사내 정상 프로그램들을 사전에 예외로 지정하여, 보안 도구가 이를 오차단하지 않도록 커스텀한다.
2. **감염 탐지·차단·추적 기능**: 사내 PC/노트북이 랜선 연결 또는 기타 경로를 통해 바이러스에 감염되었을 경우, 각 단말에 부여된 고유 ID를 기반으로 즉시 탐지·차단·추적하여 네트워크에 연결된 다른 PC/노트북으로 피해가 확산되지 않도록 한다.

## 환경 및 제약 조건
- **단말 구성**: 사내 PC는 대부분 Windows, 약 100대 규모(고정적이지 않고 변동 가능). 노트북은 Windows/Mac 혼재이며 랜선을 통해 연결하는 개인 노트북도 포함된다.
- **단말 식별**: 각 PC/노트북에 개별 관리번호(고유 ID)를 부여하여 관리할 예정이다.
- **규모**: 최소 100대 ~ 최대 1000대 수준을 가정하되, 상황에 따라 변동될 수 있다. 개발/도입은 단계적으로 확대하는 것을 전제로 한다.
- **인력**: 전담 보안 담당자는 없으며, 개발자 2~4명이 자체 개발을 목표로 한다. 관리 자동화나 인력 충원은 추후 과제로 미룬다.
- **개발 방식**: 완전 자체 개발과 오픈소스 커스터마이징을 병행할 계획이다. 상용 보안 제품의 API 활용은 비용 문제로 현재 보류 상태다.
- **기술적 제약**: macOS는 커널 확장이 제한되어 있어 프로세스 감시/차단 등 딥레벨 기능을 구현하려면 Apple의 Endpoint Security Framework(ESF) 엔타이틀먼트 승인이 필요하다. 소규모 팀이 승인받기 까다로울 수 있어, Mac 지원은 Windows 프로토타입 안정화 이후 별도로 검토한다.

## 현재 진행 단계
지금은 개발 착수 전, **필요 지식 습득 단계**이며 이와 병행하여 **보안 사례 수집·정리**도 함께 진행 중이다. 네트워크/OS 기초, 보안 개념 및 공격 기법, 기존 보안 제품의 기술을 순서대로 학습하고, 동시에 실제 해킹/공격 사례(랜섬웨어, DDoS, CSRF 등)를 수집해 감염경로·공격방법·피해규모·방어방법 등을 정리하고 있다.
